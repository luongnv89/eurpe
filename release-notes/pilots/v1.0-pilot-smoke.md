   tag.

## What this report does not cover

- **Real PDF parsing performance.** The runner uses a synthetic
  in-memory corpus stamped with the configured `call_id` so it runs
  on a fresh checkout with zero proposals on disk. For real PDF
  parsing numbers, run `eurpe benchmark indexing --corpus
  proposals/` separately.
- **Multi-coordinator agreement.** v1 records one rating per
  coordinator per section. A robust pilot would have ≥ 2
  coordinators per section to surface disagreement; this is
  deferred to v1.1.
- **Cross-call generalisation.** The auto-mode pilot exercises one
  call only. Multi-call generalisation lands in v1.1 per the PRD's
  *Post-MVP v1.1* section.
